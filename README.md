# QR Code Component

This is a solution to the [QR code component challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H).

## 📱 Overview

A clean, responsive QR code card component built with semantic HTML5 and CSS3. The design is fully responsive and works perfectly on all screen sizes from mobile to desktop.

## 🎯 Features

- Fully responsive design (Mobile First approach)
- Clean and minimal UI
- Semantic HTML5 markup
- CSS custom properties (HSL colors)
- Flexbox for centering
- Media queries for responsive breakpoints

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, Custom Properties, Media Queries)
