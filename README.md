## 📚 What I Learned

This was my first real project, and it taught me several important lessons:

### 1. The Gap Between Theory and Practice

Understanding CSS concepts like Flexbox, Media Queries, and HSL colors is one thing, but applying them to build a real component was a completely different challenge. I realized that true learning comes from doing.

### 2. Responsive Design

I learned how to use `min-height: 100vh` with Flexbox to center content vertically, and how to use Media Queries to adjust the layout for smaller screens. I also understood the importance of using `max-width` instead of fixed `width` to prevent overflow on narrow devices.

### 3. CSS Best Practices

I learned to use meaningful class names (like `.qr-card` instead of `.box1`), avoid duplicate styles (like removing unnecessary `box-shadow` from `body`), and organize CSS for readability.

### 4. Problem-Solving with DevTools

I used browser developer tools to debug layout issues, check responsive behavior, and test different screen sizes. This was invaluable for identifying and fixing problems.

### 5. Deployment with Git and GitHub Pages

I learned how to push code to GitHub, manage commits, and deploy a live project using GitHub Pages. This gave me a real sense of accomplishment.
